**Windows only.** Download the zip, unzip it, and run the setup wizard inside.
Nothing else is needed — no Node, no npm.

It is not code-signed, so Windows shows a blue "Windows protected your PC"
notice. Click **More info**, then **Run anyway**. That means the publisher is
unverified, not that anything is wrong with the file.

On first run your computer asks whether to allow Pen-pal Pet through the
firewall. Say yes, and tick **Private networks only**.

There is no macOS or Linux build. The app has never been run on either, so
nothing is offered for them yet.
